# @lankithagallage/ai-context-core

Core domain, application, and infrastructure for
[ai-context](https://github.com/lankithagallage/ai-context).

This package is an internal dependency of `@lankithagallage/ai-context-cli` and
`@lankithagallage/ai-context-mcp`. You do not need to install it directly.

For usage, see the [ai-context README](https://github.com/lankithagallage/ai-context).
